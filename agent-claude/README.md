# Claude Agent

Chat with Claude Code through ACP. Install Node.js and the Claude Code CLI, then sign in with Claude Code. The first connection downloads the adapter.

```sh
fiveleaf plugin install agent-claude
```

Enable the plugin in **Settings → Plugins**.

Select **Claude Code** in the chat agent picker. FiveLeaf launches `npx -y @agentclientprotocol/claude-agent-acp@0.107.0` using your local account configuration.
