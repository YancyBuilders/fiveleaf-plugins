# Kimi Code Agent

Connect the installed Kimi Code CLI to FiveLeaf over ACP. Sign in and configure a model in `kimi` before opening a chat.

```sh
fiveleaf plugin install agent-kimi
```

Enable the plugin in **Settings → Plugins**.

Select **Kimi Code** in the chat agent picker. FiveLeaf launches `kimi acp` using your local account configuration.
