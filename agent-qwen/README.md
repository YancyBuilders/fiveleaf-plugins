# Qwen Code Agent

Connect the installed Qwen Code CLI to FiveLeaf over ACP. Sign in and configure a model in `qwen` before opening a chat.

```sh
fiveleaf plugin install agent-qwen
```

Enable the plugin in **Settings → Plugins**.

Select **Qwen Code** in the chat agent picker. FiveLeaf launches `qwen --acp` using your local account configuration.
