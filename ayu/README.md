# Ayu

Warm amber accents with light and dark palettes. Follows light and dark appearance.

![Ayu preview](preview.svg)

```sh
fiveleaf plugin install ayu
```

Open **Color Theme…** in the command palette and choose **Ayu**.

Light and dark palettes from `ayu-theme/ayu-colors` 9.1.0, with FiveLeaf adjustments for legibility. [Upstream revision](https://github.com/ayu-theme/ayu-colors/tree/c6e86054896ef10c69ba899dc11fdad0e004d4d3) · [MIT license](licenses/ayu-colors.txt)
