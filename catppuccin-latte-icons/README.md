# Catppuccin Latte Icons

Catppuccin Latte artwork for files and folders in FiveLeaf.

![Catppuccin Latte Icons preview](preview.svg)

```sh
fiveleaf plugin install catppuccin-latte-icons
```

Open **File Icon Theme…** in the command palette and choose **Catppuccin Latte**.

Catppuccin SVG geometry and colors are copied unchanged from `icons/{latte,mocha}`. Local filenames use shared semantic names; both flavors retain their upstream palettes.

Sources for individual icons are recorded in [sources.json](assets/sources.json). [Upstream snapshot](https://github.com/catppuccin/zed-icons/tree/f695ec0d81d53d6776471c3d3cad702cf11670e3) · [Artwork license](assets/LICENSE)
