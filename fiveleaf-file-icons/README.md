# FiveLeaf File Icons

Original FiveLeaf file and folder symbols, tinted by language and color theme.

![FiveLeaf File Icons preview](preview.svg)

```sh
fiveleaf plugin install fiveleaf-file-icons
```

Open **File Icon Theme…** in the command palette and choose **FiveLeaf**.

The filename associations and language tints are from FiveLeaf. The ten shared shapes use Lucide and Feather artwork. [Artwork license](assets/LICENSE)
