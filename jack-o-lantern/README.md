# Jack-o'-Lantern

Pumpkin orange by candlelight. Dark color theme.

![Jack-o'-Lantern preview](preview.svg)

```sh
fiveleaf plugin install jack-o-lantern
```

Open **Color Theme…** in the command palette and choose **Jack-o'-Lantern**.

FiveLeaf's candlelit pumpkin, plum and green potion, and crimson and old gold palettes.
