# Witch's Brew

Plum dark, with slime green. Dark color theme.

![Witch's Brew preview](preview.svg)

```sh
fiveleaf plugin install witchs-brew
```

Open **Color Theme…** in the command palette and choose **Witch's Brew**.

FiveLeaf's candlelit pumpkin, plum and green potion, and crimson and old gold palettes.
